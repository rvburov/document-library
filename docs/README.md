# Документация проекта

«Библиотека PDF» — настольная программа для поиска и чтения PDF-документов (Avalonia + .NET +
EF Core/SQLite с FTS5). Документация — для разработчиков: как устроена и работает программа.
Встроенной инструкции пользователя нет (решение по [infrastructure.md](infrastructure.md),
вопрос 3).

Планы развития — [ROADMAP.md](ROADMAP.md). Согласованный макет — [mockup.md](mockup.md),
инфраструктура разработки и принятые решения — [infrastructure.md](infrastructure.md). Правила для
ИИ-агентов — [AGENTS.md](../AGENTS.md).

## Как вести документацию

Документы по фичам следуют единому шаблону: **Назначение → Где в коде → Как работает →
Взаимодействия → Связанные документы**; где есть что сказать — еще «Проверено и не проверено».
Имена файлов и папок — `lowercase-kebab-case`, содержимое — на русском, без буквы «е с точками».
Ссылки на код относительные. Связи между документами помечаются `[[имя]]`.

- Новый документ — строка в этой карте.
- Изменилось поведение — правится документ фичи в том же коммите, что и код.
- Крупные документы дробятся по подтемам в одноименную папку, `overview.md` остается точкой входа.
- Модули CI и выпуска отделяемы: вне своих файлов они упомянуты только здесь, и при удалении
  модуля его строка убирается из карты вместе с ним.
