# Макет «Библиотека PDF»

Макет — десять экранов: четыре основных и шесть разделов настроек.

Приложение работает только с PDF: desktop на Avalonia, без сервера и учетных записей, файлы не
копируются — в базе лежат только ссылки, прочитанный текст, миниатюры и метки.

## Решения 21.10.2026: внешний вид

Пользователь решил: внешний вид программы — общий набор стилей и разметки экранов (цвета, шрифты,
иконки, размеры, панели, линии и ручки ширины). Это решение главнее макета ниже во всем, что
касается вида; что программа умеет, остается по макету. Что изменилось против макета:

| Было по макету | Стало |
|---|---|
| Свои цвета (вторичный текст `#6C6C70`, акцент `#0A64D8`, подсветка `#FFE98A`), шрифт 13/11 px | цвета, шрифты, иконки и размеры общего набора стилей (шрифт 12/10 px) |
| Плитка «A4 · 48 с.» | плитка — миниатюра с красной лентой «PDF»; формат листов — строкой справа |
| Панель чтения — отдельный экран с узкой лентой слева, рельсом миниатюр страниц и масштабом | правая колонка окна рядом с лентой, с ручкой ширины; только «как в документе» — настоящие страницы, без переключателя режимов; без рельса миниатюр и без масштаба — размер листа задают ширина панели и «развернуть документ» |
| Галочки на карточках для выбора документов | выбор щелчком: `Shift` / `Ctrl` добавляют, `Ctrl+Shift` — диапазон |
| Список разделов настроек внутри экрана настроек | список разделов в боковой панели окна; внутри раздела — блоки настроек, как в макете |
| Счетчики документов у источников в боковой панели | дерево без счетчиков; у источника — строка состояния («читаю папку…», «недоступна») |

Режим «Текст» в панели чтения появился и в тот же день убран по решению пользователя: документ
всегда показывается страницами. Масштаб, шрифт и тема — как в макете: сегменты 90–125 % и «мелкий /
стандартный / крупный», плитки темы.

Экраны связаны ссылками: «Прочитать» ведет в панель чтения, значок внизу левой панели — в настройки.

## Источники, группы и метки

Все создается одной кнопкой «+» в верхней строке боковой панели. Меню из трех пунктов:

| Пункт | Окно | Что получается |
|---|---|---|
| Источник | папка (выбрать или вставить путь, в том числе сетевой), название — по умолчанию имя папки, группа | строка в разделе «Источники»; программа находит PDF в папке и подпапках и читает их текст |
| Группа источников | название и галочки источников, которые в нее входят | раскрывающаяся строка с иконкой папок; галочка группы включает и выключает все ее источники |
| Метка | название и цвет; галочка «Сразу поставить выбранным документам» | строка в разделе «Метки»; нажатие на метку оставляет в ленте только документы с ней |

Боковая панель показывает только подключенные папки и группы — подпапки с диска в ней не
раскрываются. Группа — свой уровень вложенности поверх папок, на диске ничего не меняется.

Метки ставятся документам так: отметить документы галочками → «Метка» в панели действий внизу →
список меток с галочками. Галочка ставит метку всем выбранным, снятая — убирает. Оттуда же можно
создать новую метку. На карточке метки видны справа, под типом документа.

## Разделы настроек

### Общее

| Настройка | Что делает |
|---|---|
| Запускать при входе в систему | программа стартует сама и проверяет папки; доступно только установленной копии |
| Работать в фоне при закрытом окне | окно сворачивается в значок у часов, наблюдение и чтение продолжаются |
| Уведомления: новые документы, чтение закончено | системные уведомления, стандартно выключены |
| Программа для кнопки «Открыть» | «Как в системе» или своя программа для PDF |
| Открывать при запуске последний документ | на той странице, где закончили читать |

### Источники и чтение

Список папок рассчитан на десятки и сотни папок:

- одна папка — одна строка: название, путь, число PDF, состояние;
- поиск по названию и пути, фильтр «Все / С проблемами / Читаются» с числами;
- папки с проблемами (недоступна, отключена) стоят в начале списка и подсвечены;
- «Проверить все» и «Добавить папку» — одной кнопкой над списком, остальные действия — в меню «⋯» строки;
- список прокручивается внутри своей рамки, заголовок колонок остается на месте.

Добавить папку можно двумя способами: выбрать в окне или вставить путь, в том числе сетевой
(`\\srv-01\archive`). Отдельной кнопки для сетевых папок нет.

Ниже — наблюдение за папками, чтение новых документов, порог размера файла, маски исключений и
состояние кеша с кнопкой «Очистить».

### Лента и карточки

Сверху — пример карточки, который сразу меняется вместе с настройками ниже.

| Группа | Настройка | Что делает |
|---|---|---|
| Карточка | Размер карточки: маленькая / средняя / большая | высота строки, размер миниатюры и сколько строк найденного текста видно: 1, 3 или 6 |
| Карточка | Миниатюра первой страницы | выключено — на плитке только формат листа и число страниц |
| Что показывать | Где лежит файл | строка «источник · папка · имя файла» под названием |
| Что показывать | Размер и страницы | «3,1 МБ · 48 стр. · A4» справа |
| Что показывать | Тип документа | голубая метка справа |
| Какие документы | Документы, которых нет на диске | показывать с пометкой «файл не найден» или скрыть |
| Какие документы | Сканы без текстового слоя | показывать с пометкой «скан, без текста» или скрыть |

### Оформление

Тема (светлая, темная, как в системе), масштаб интерфейса (90–125%) и размер шрифта (мелкий,
стандартный, крупный) с примером текста. Страницы PDF в панели чтения остаются белыми в любой теме.

### Диагностика

Журнал работы: время, уровень (ошибка, предупреждение, сведения) и сообщение. Фильтр по уровню,
подробности по нажатию на строку, выгрузка в CSV и очистка. Журнал хранится в `logs.db`, записи старше
30 дней удаляются сами.

### О программе

Версия и дата сборки; обновления из папки в сети с кнопкой «Проверить» и автообновлением; папка с
данными (`library.db`, `library-cache.db`, `logs.db`); система.

| Один вид ленты — карточки | так и остается: без переключателя Лента / Сетка / Таблица | лишний орган управления в навбаре |
| Чипы «не прочитан», «файл не найден» | плюс «изменен · перечитать» и «скан, без текста» | видно, почему документ не нашелся по содержимому |

## Предлагаемые функции

### Этап 1 — лента, поиск, панель чтения

- Лента карточек с миниатюрой первой страницы, виртуализация для больших библиотек.
- Поиск по названию и по тексту внутри PDF (FTS5) с подсветкой, «е» = «е», числа и даты как написаны.
- Панель чтения справа: настоящие страницы PDF, поиск по документу с подсветкой на странице, переходы
  F3 / Shift+F3.
- Фоновое чтение текста с прогрессом, остановкой и продолжением; кеш с очисткой.
- Фильтр «Тип документа», сортировка, размер карточки. Сочетания клавиш фиксированные, без раздела
  настроек для их переназначения.

### Этап 2 — то, чего не хватает отдельному приложению

- **Источники.** Папки на диске и в сети; программа следит за ними сама: новые PDF
  появляются в ленте, измененные помечаются и перечитываются, удаленные — «файл не найден».
- **Сортировка по релевантности** для поисковой выдачи.
- **Выделение нескольких документов** и панель действий: метка, копировать в папку.
- **Группы источников и метки** — создаются кнопкой «+», метки ставятся из списка с галочками.
- **В панели чтения:** миниатюры страниц со счетчиком совпадений и масштаб.
- **Темная тема.**

### Этап 3 — позже

- **Инструменты PDF:** объединить, разделить, извлечь и повернуть страницы, сжать сканы (PDFsharp);
  водяной знак, переименование по шаблону, опись в табличный файл.
- **Полки:** Избранное, Недавние, свои полки и умные полки — сохраненный поиск с фильтрами.
- **Оглавление и заметки в панели чтения:** переход по закладкам PDF; выделение фрагмента с комментарием,
  который хранится в базе, а PDF не меняется.
- **Распознавание текста сканов (OCR)**, чтобы они искались по содержимому.
- **Сравнение версий** по тексту и по изображению листов.
- **Общая библиотека отдела:** файл базы в сетевой папке; при многих пишущих — PostgreSQL.
- Быстрый просмотр по пробелу, командная палитра Ctrl+K, печать нескольких документов.

## Стек

Пакеты: Avalonia 11.2 (Fluent), .NET 10, CommunityToolkit.Mvvm, EF Core 9 + SQLite (FTS5), PdfPig,
Docnet.Core, SkiaSharp, Serilog. Для инструментов позже добавятся PDFsharp и библиотека для описи
в табличный файл.

## Модель данных — набросок

Таблицы базы:

| Таблица | Поля |
|---|---|
| `sources` | id, name, path, group_id, watch, last_scan |
| `documents` | id, source_id, rel_path, file_name, size, mtime, md5, pages, sheet_formats (json), a4_sheets, text_state, pdf_title, pdf_author, pdf_producer, pdf_created, pdf_modified, doc_type, added_at |
| `doc_pages_fts` | FTS5: document_id, page, text — постранично |
| `source_groups` | id, name, position |
| `tags`, `document_tags` | метки (id, name, color) и их связь с документами |
| `shelves`, `shelf_items` | полки, позже; у умной полки вместо списка — сохраненный запрос (json) |
| `notes` | заметки к страницам, позже: id, document_id, page, rect, color, quote, text, author, created_at |

Миниатюры — в отдельном файле кеша, который можно очистить без потери данных. Автор —
`учетка@компьютер`.
