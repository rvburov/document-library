# Ручная проверка на настоящих файлах

## Назначение

Что тесты и стенды проверить не могут: настоящие инженерные PDF человека, сетевой диск, установка в
систему, системные уведомления, мониторы с масштабом. Тесты и стенд экранов работают на собранных
в тесте документах; этот список — для проверки в работающей программе перед выпуском и после
заметных правок.

## Первый запуск и источники

- [ ] Пустая папка данных → экран первого запуска; «Добавить папку» с локальной папкой и с сетевой
      (`\\сервер\папка` на Windows, смонтированная папка на macOS и Linux).
- [ ] Перетаскивание папки в окно добавляет источник.
- [ ] Папка на десятки тысяч PDF: проверка заканчивается, счетчики в «Источниках и чтении» верны,
      интерфейс не замирает.
- [ ] Выключить сетевой диск → источник «недоступен», документы не пропадают; включить → через
      ≤ 10 минут или по «Проверить все» снова доступен.

## Чтение и поиск

- [ ] Чтение настоящих чертежей и руководств: ход, «осталось около …», уведомление по окончании.
- [ ] Сканы без текстового слоя помечены «скан, без текста» и ищутся по названию.
- [ ] Файл тяжелее порога остается в ленте и ищется по названию.
- [ ] Поиск по номеру чертежа, по ГОСТу, по фразе из текста; подсветка в карточке и на листах.
- [ ] Тип документа на своих папках: коды ЕСКД в именах, спецификации без кода, папки «Паспорта»,
      «Протоколы». Что определилось неверно — записать в ROADMAP с примером имени.
- [ ] Словоформы: «насоса» при поиске «насос» не находится (ожидаемо, открытый пункт ROADMAP).

## Наблюдение за папками

- [ ] Положить PDF в папку источника → карточка появляется через несколько секунд.
- [ ] Удалить → «файл не найден»; переименовать или перенести → метки сохраняются.
- [ ] Временные файлы `~$*.pdf` в ленту не попадают.

## Панель чтения

- [ ] Том в сотни страниц: открытие, прокрутка, переход по совпадениям без рывков.
- [ ] Чертеж A1 и A0 из САПР: масштаб, подсветка надписей, в том числе на полях штампа.
- [ ] «Открывать при запуске последний документ» возвращает на ту же страницу.

## Оболочка

- [ ] Установка `PdfLibrary-Setup` без прав администратора на каждой ОС; ярлыки, «Приложения»
      Windows, Launchpad, меню приложений Linux.
- [ ] Обновление из папки обновлений: «Проверить», обновление, автообновление при запуске;
      рядом обновился и установщик.
- [ ] Удаление: с данными и без; чужие файлы в общей папке установки целы.
- [ ] Автозапуск при входе в систему, работа в фоне со значком у часов, «Открыть» из значка.
- [ ] Системные уведомления «Новые документы» и «Чтение закончено» на каждой ОС.
- [ ] Масштаб ОС 150–200 % и масштаб интерфейса 125 %: ничего не обрезано.
- [ ] Темная тема на всех экранах, листы PDF белые.

## Диагностика

- [ ] «Диагностика» показывает журнал, фильтр «Ошибки», выгрузка в CSV открывается табличным
      редактором с русскими буквами.
- [ ] После принудительного закрытия программы в `crash.log` нет мусора, программа стартует.
