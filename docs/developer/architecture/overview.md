# Как устроена программа

## Назначение

Карта программы для разработчика: слои, запуск, потоки, данные. Подробности по разделам — в
[features/](../features/), правила кода — в [AGENTS.md](../../../AGENTS.md).

## Слои

| Папка | Что | От чего зависит |
|---|---|---|
| `Core/Documents/` | PDF без интерфейса: текст и форматы листов (`DocTextExtractor`, `SheetFormats`), название (`DocTitle`), тип документа (`DocTypes`), страницы и места слов (`DocPageSource`), миниатюры (`DocThumbnail`), подсветка (`DocHighlight`), отметки файлов (`DocStamps`), очередь PDFium (`PdfGate`) | PdfPig, Docnet.Core, SkiaSharp |
| `Core/Library/` | документ и источник в памяти (`DocItem`, `SourceItem`), обход папок (`SourceScanner`), сборка ленты (`FeedFilter`) | `Core/Documents` |
| `Database/` | `library.db` на EF Core (`LibraryDbContext`, `LibraryStore`), кеш прочитанного `library-cache.db` (`DocIndex/`), `SqliteGate` | EF Core, Microsoft.Data.Sqlite |
| `Services/` | библиотека целиком (`LibraryService`): источники, проверка и наблюдение, фоновое чтение, поиск; действия с файлами (`DocActions`) | все выше |
| `Views/`, `Controls/`, `Assets/Styles/` | интерфейс Avalonia: лента, панель чтения, первый запуск, настройки, диалоги; токены и темы | `Services` |
| `Logging/` | журнал Serilog в `logs.db`, `crash.log`, медленные операции и зависания | Serilog |
| `Setup/` | установщик, удаление, обновление из папки | — |
| `Notifications/`, `Utils/` | системные уведомления; настройки, масштаб, автозапуск, фоновый режим, один экземпляр | — |

`Core` не знает об интерфейсе и базе — его тесты идут без Avalonia и без SQLite.

## Запуск

[Program.cs](../../../Program.cs):

1. Культура ru-RU, предохранители падений (`crash.log`).
2. Режим: `--apply-update` (самозамена), установщик или удаление по имени файла
   ([install-and-update.md](../guides/install-and-update.md)), иначе программа.
3. Один экземпляр на папку данных (`SingleInstance`): второй запуск будит первый и выходит.
4. Журнал (`AppLog.Init`), менеджер системных уведомлений, Avalonia.

[App.axaml.cs](../../../App.axaml.cs): заставка, подготовка в фоне (`App.Prepare`: база,
миграции, настройки, кеш, `LibraryService`), главное окно, значок у часов, автообновление при
старте. Закрытие окна при «Работать в фоне» прячет его, а не выходит.

## Потоки

- **Память библиотеки — только в UI-потоке.** `LibraryService` получает делегат `post`: обход
  папок, запись в базу, перепись кеша и поиск идут в фоне, а итог переносится в UI-поток. Лента
  читает документы без замков, событие `Changed` приходит в UI-потоке. В тестах `post` выполняет
  действие под замком теста.
- **Проверки папок — по одной** (`SemaphoreSlim`): два обхода сетевой папки параллельно не
  быстрее одного.
- **Чтение текста — свой поток** `DocIndexService`: очередь путей, ход и оценка оставшегося
  времени (`DocReadPace`), состояния карточек пачками раз в 500 мс.
- **PDFium — одна очередь** `PdfGate`: миниатюры, страницы панели чтения и чтение не рисуют
  одновременно.

## Данные

| Файл | Что | Как устроен |
|---|---|---|
| `library.db` | источники, группы, метки, документы, метки документов, настройки | EF Core, одна начальная миграция; только то, что сделал человек или что дешево узнать по пути |
| `library-cache.db` | текст документов для поиска, страницы, форматы листов, название из свойств PDF | сырой SQLite с FTS5 (`unicode61 remove_diacritics 2`), ключ — путь файла; пересобираемый, при повреждении пересоздается |
| `thumbs/` | PNG первых страниц | имя содержит время правки и размер документа; старше 60 дней — убираются |
| `logs.db` | журнал | Serilog, 30 дней |

Документ в `library.db` хранит путь внутри источника, размер, время правки, тип по пути и время
находки. Состояние чтения, страницы, форматы и название берутся из кеша при старте и после
каждого прочитанного файла (`LibraryService.ApplyEntry`); там же тип уточняется по названию.

Подключения SQLite — только через [SqliteGate](../../../Database/SqliteGate.cs).

## Сеть

Программе сеть не нужна: сетевые папки — это файлы. Все сетевые API запрещены
[BannedSymbols.txt](../../../BannedSymbols.txt) (ошибка сборки) и тестом `NoNetworkTests`.
