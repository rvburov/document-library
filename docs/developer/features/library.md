# Лента, поиск и источники

## Назначение

Главный экран: PDF из подключенных папок лентой карточек, поиск по тексту внутри файлов и по
названию, фильтры по источникам, типу и меткам. Документы остаются файлами на своих местах —
программа хранит только то, что сделал человек (источники, группы, метки), и пересобираемый кеш
прочитанного.

## Как работает

### Источники и группы

Источник — папка (локальная или сетевая) с подпапками. Добавляется кнопкой «+», перетаскиванием
папки в окно или на экране первого запуска. Источники можно собрать в группы; в боковой панели —
дерево с галочками: снятая галочка убирает документы источника из ленты, не удаляя их.

Один документ, попавший в два источника (папка и ее подпапка), читается один раз: кеш
прочитанного ведется по пути файла.

### Проверка папок и наблюдение

`SourceScanner` обходит папку рекурсивно; время правки и размер приходят вместе с листингом,
отдельно к каждому файлу диск не спрашивается — на сетевой папке это разница в разы. Скрытые и
системные файлы пропускаются, как и маски «Пропускать файлы» (по умолчанию `~$*.pdf`).

Итог сверяется с `library.db`:

- новый файл — новый документ, тип по пути;
- тот же размер и время правки в другом месте — перенос, метки сохраняются;
- файла нет — «файл не найден» (только если обход дошел до конца);
- папка не ответила — источник «недоступен», документы не помечаются пропавшими.

Наблюдение — `FileSystemWatcher` на каждый источник с паузой 2 с, чтобы пачка изменений дала одну
проверку, плюс сверка всех папок раз в 10 минут: на сетевых папках события теряются. Выключается
настройкой «Следить за папками».

### Чтение

Новое и измененное уходит в очередь `DocIndexService` (если включено «Читать новые документы
сразу»; иначе — кнопкой «Прочитать»). Разбор — `DocTextExtractor`: текст первых 300 страниц,
форматы всех листов (`SheetFormats`: «A1 × 1, A3 × 2»), число страниц, название из свойств PDF
(`DocTitle` отбрасывает пустые и служебные названия). Файлы тяжелее порога «Не читать файлы
тяжелее» (по умолчанию 200 МБ) остаются в ленте и ищутся только по названию. Сканы без текстового
слоя помечаются «скан, без текста».

Ход чтения — кольцо в панели разделов и строка «осталось около N минут»; оценка — по скорости
этого прогона без разогрева (`DocReadPace`). По окончании — системное уведомление, если включено.

### Тип документа

`DocTypes.Of(имя файла, папка, название)` — голубая метка на карточке и фильтр «Тип документа».
Порядок признаков:

1. код документа ЕСКД в имени: «АБВГ.301122.001 ВО» — чертеж, «ЦНС-38-44_РЭ» — руководство, «Г3» —
   схема (ГОСТ 2.102, 2.601, 2.701);
2. слова в имени: «ГОСТ 2.104», «СП 31.13330», «Договор», «Протокол испытаний»;
3. слова в названии из свойств PDF (известно после чтения);
4. папка внутри источника, ближняя важнее дальней: «Паспорта», «Протоколы»;
5. обозначение без кода («АБВГ.301122.001») — чертеж детали.

Обозначение без кода стоит последним: так же обозначается спецификация, и название («Спецификация
АБВГ.301122.001») или папка говорят точнее. В `library.db` лежит тип по пути (известен сразу после
проверки), а с названием тип пересчитывается в памяти при каждом применении кеша
(`LibraryService.ApplyEntry`). Ничего не подошло — типа нет, в фильтре это «Без типа».

### Поиск

Строка поиска ищет сразу в двух местах:

- **по тексту** — FTS5 в `library-cache.db`. Слова запроса соединяются через AND, последнее слово —
  по началу («автоматизир» находит «автоматизированных»), «е» ищется и как «е с точками», число
  «30772» — и как «30 772». Карточка показывает фрагменты с подсветкой; строк столько, сколько
  разрешает размер карточки (1, 3 или 6);
- **по названию, имени файла и папке** — в памяти: все слова должны найтись, каждое — с начала
  слова.

Порядок «По релевантности»: найденное по названию выше найденного только по тексту, внутри —
место в выдаче FTS. Другие порядки — по изменению файла, по названию, по размеру. Строка состояния
говорит, сколько найдено внутри текста и сколько по названию; не ответил кеш — так и пишет, а не
делает вид, что внутри документов ничего нет.

Словоформы не различаются: «насос» не находит «насоса», если это не последнее слово запроса —
открытый пункт [ROADMAP](../../ROADMAP.md).

### Метки и действия с выбранными

Метки с цветом — в боковой панели (фильтр ленты) и на карточке. Выбранные галочками документы:
панель внизу ленты — «Метка» (поставить или снять) и «Копировать в папку».

## Взаимодействия

- Панель чтения ([reader.md](reader.md)) открывается из карточки; список слева — та же лента с
  тем же поиском.
- Настройки «Источники и чтение» и «Лента и карточки» меняют поведение сразу, без перезапуска.
- Журнал: каждая проверка папки («новых N, измененных N, пропавших N»), чтение, сбои — в
  `logs.db`.

## Проверено и не проверено

Тесты: `DocTypesTests`, `FeedFilterTests`, `SmallPartsTests` (маски, поиск по названию),
`LibraryServiceTests` (папка → чтение → поиск, пропавший файл, наблюдение, недоступная папка,
уточнение типа по названию), `DocTextIndexTests`, `DocIndexServiceTests`; стенд экранов — лента,
поиск, фильтры. Проверено на сгенерированных PDF; поведение на настоящих инженерных папках
пользователя и на сетевом диске — по [manual-check.md](../qa-checklists/manual-check.md).
