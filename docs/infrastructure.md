# Инфраструктура разработки: решения

Опись того, на чем держится разработка «Библиотеки PDF»: сборка, запуск, журнал, база, тесты,
CI, выпуск, документация. По каждому пункту — решение:

- **Есть** — в проекте и работает;
- **Есть, урезано** — в проекте только то, что нужно программе для PDF;
- **Нет** — не нужно;
- **Позже** — нужно, открытый пункт [ROADMAP](ROADMAP.md).

Пункты, которые требует согласованный макет (автозапуск, фоновый режим, уведомления, обновления,
диагностика), отмечены «по макету». Ответы пользователя на вопросы — в конце.

## 1. Проект и сборка

| Что | О чем | Решение |
|---|---|---|
| `.csproj` | `Nullable`, `ImplicitUsings`, версия только в csproj, ReadyToRun без composite, `IncludeNativeLibrariesForSelfExtract` (иначе в одном файле не грузятся Skia и SQLite), без тримминга, `BannedApiAnalyzers` | **Есть** |
| Пакеты | Avalonia 11.2.3 (Fluent, Inter), CommunityToolkit.Mvvm, EF Core + SQLite, PdfPig, Docnet.Core (PDFium), SkiaSharp 2.88.9 (закреплен под Avalonia), Serilog + запись в SQLite, DesktopNotifications, закрепленные версии из-за уязвимостей | **Есть** |
| Пакеты для таблиц, разметки, редактора текста, PostgreSQL | — | **Нет**; PDFsharp — позже, для инструментов |
| Два таргета (`net10.0` и `net10.0-windows10.0.17763`) | Windows-таргет нужен только ради системных уведомлений Windows | **Есть** — по макету (уведомления в «Общем») |
| `Directory.Build.props` | весь вывод сборки в `artifacts/` | **Есть** |
| `nuget.config` | кеш пакетов внутри репозитория (`packages/`), только nuget.org | **Есть** |
| `.gitattributes`, `.gitignore` | LF для текстов и `.sh`, базы и кеши не в git | **Есть** |
| `dotnet-tools.json` | `dotnet-ef` для миграций, версия выровнена с EF Core | **Есть** |
| `global.json` | закрепляет SDK 10 | **Есть** |
| `app.manifest` | DPI PerMonitorV2, запуск без прав администратора | **Есть** |
| `BannedSymbols.txt` | запрет сетевых API, нарушение — ошибка сборки | **Есть** — запрет всей сети без исключений: программе сеть не нужна, сетевые папки — это файлы |

## 3. База и ядро библиотеки

| Что | О чем | Решение |
|---|---|---|
| `library.db` | база на EF Core с одной начальной миграцией: источники, группы, метки, документы, настройки | **Есть** |
| `DocIndex/` | `library-cache.db` с FTS5 (`unicode61 remove_diacritics 2`), пересоздается при повреждении; фоновая очередь чтения с ходом и оценкой времени | **Есть** — ядро программы |
| `Core/Documents/` | `PdfGate` (все вызовы PDFium через одну очередь), миниатюры, страницы PDF и места слов, текст PDF, подсветка найденного, геометрия страницы | **Есть** — только PDF |
| `SqliteGate` | обход гонки пула Microsoft.Data.Sqlite | **Есть**, пока EF Core 9; убрать, если выйдет версия с исправлением |
| `WalCheckpointer`, `SqliteMaintenance` | сжатие журнала WAL и разросшихся файлов | **Позже** |
| Наблюдение за папками | `FileSystemWatcher` плюс периодическая сверка для сетевых папок, где события теряются | **Есть** |
| Несколько баз, PostgreSQL, сетевые пути базы, резервное копирование | — | **Нет** (резервное копирование убрано из макета) |

## Вопросы и ответы пользователя (20.10.2026)

1. **Правила git** — автор Roman Burov, сообщения по-русски `тип(область): суть`, основная ветка
   репозитория — `master`, только перемоткой.
2. **Параллельная работа** — каждая задача в своей рабочей папке git worktree и своей ветке;
   готовое вливается в `master` перемоткой.
3. **Встроенная инструкция пользователя** — не нужна.
4. **Иконка программы** — пока временная (`Scripts/draw-icon.py`); своя — пункт ROADMAP.
5. **Техническое имя** — `PdfLibrary`: `PdfLibrary.exe`, `PdfLibrary-Setup.exe`, папка данных
   `PdfLibrary`, как в макете на экране «О программе».
6. **Тип документа** — по коду ЕСКД в имени файла («ВО» — чертеж общего вида, «РЭ» — руководство),
   затем по словам в имени и в названии из свойств PDF, по папке; иначе без типа.

Отличия от первоначального плана:

- Вместо стенда одной панели чтения — стенд всех экранов `Tests/Screens`.
- Кеш прочитанного называется `library-cache.db`, а не `docs_index.db`.
- Интеграционные тесты и стенд экранов гоняются и в проверке веток: наборы быстрые.
- `Tests/Benchmarks` и обслуживание SQLite (`WalCheckpointer`, `SqliteMaintenance`) — открытые
  пункты [ROADMAP](ROADMAP.md).
