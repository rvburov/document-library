# Инфраструктура разработки: что взять из SmartBase

Опись того, на чем держится разработка [SmartBase](https://github.com/rvburov/SmartBase): правила для
агентов, сборка, запуск, журнал, база, тесты, CI, выпуск, документация. По каждому пункту — решение
для «Библиотеки PDF»:

- **Беру** — переношу как есть, меняю только имена;
- **Адаптирую** — беру основу, убираю то, что относится к другим разделам SmartBase;
- **Не беру** — в новом приложении не нужно.

Пункты, которые требует согласованный макет (автозапуск, фоновый режим, уведомления, обновления,
диагностика), отмечены «по макету». Открытые вопросы — в конце.

## 1. Правила для агентов — AGENTS.md

| Раздел AGENTS.md | О чем | Решение |
|---|---|---|
| Параллельная работа агентов | каждый чат — в своем git worktree и ветке, `Scripts/worktree.sh check/new/sync/merge`, слияние в `main` только fast-forward, «Сделай и отправь», «Сделай через PR» | **Адаптирую** — если работаете в нескольких чатах на своем компьютере (вопрос 2) |
| Облачная копия | ветку пушить сразу, в `main` — только по просьбе: rebase → тесты → push fast-forward; после 3 отказов остановиться | **Беру** |
| Проект | карта папок | **Адаптирую** — новая карта, без `Extensions/`, `Integrations/` |
| Сборка и запуск | команды запуска по таргетам, не трогать запущенную программу пользователя | **Беру** |
| Тесты | «Тесты гонять всегда»: `Tests/Unit` во время работы, `./Tests/run-all.sh` перед коммитом, честные числа, упавшее не выдавать за прошедшее, мутационная проверка новых тестов, «проверено на стенде — не на ваших файлах» | **Беру** |
| Правила кода | стиль окружения, комментарии по-русски, интерфейс только токенами и готовыми виджетами, миграции без потери данных, все подключения SQLite через `SqliteGate`, ловушка `TextBox.TextChanged` в Avalonia 11.2 | **Беру**, без пар миграций для PostgreSQL, расширений и интеграций |
| Тексты | без буквы «е» (кроме кода свертки поиска), без названий сторонних программ, сведения о строке — в строке, а не в подсказке, документация меняется вместе с кодом, ROADMAP всегда актуален | **Беру** |
| Секреты | не в git, не в логах, не в чате | **Беру** (секретов у программы почти нет) |
| Git | коммит и пуш только по просьбе; линейный `main`; без `--force`; сообщения по-русски `тип(область): суть`; без `Co-Authored-By` и подписей ИИ; автор и коммиттер — Roman Burov | **Беру** (вопрос 1) |
| Работа с пользователем | по-русски; продуктовые развилки решает пользователь (1–4 вопроса с вариантами, рекомендуемый первым), технические — агент; без подагентов, пока не попросят | **Беру** |
| Среда пользователей | SQLite на медленной сетевой папке, которая пропадает; нет прав администратора | **Беру** — источники бывают сетевыми |

## 3. Проект и сборка

| Что | О чем | Решение |
|---|---|---|
| `.csproj` | `Nullable`, `ImplicitUsings`, версия только в csproj, ReadyToRun без composite, `IncludeNativeLibrariesForSelfExtract` (иначе в одном файле не грузятся Skia и SQLite), без тримминга, `BannedApiAnalyzers` | **Адаптирую** |
| Пакеты | Avalonia 11.2.3 (Fluent, Inter), CommunityToolkit.Mvvm, EF Core + SQLite, PdfPig, Docnet.Core (PDFium), SkiaSharp 2.88.9 (закреплен под Avalonia), Serilog + запись в SQLite, DesktopNotifications, закрепленные версии из-за уязвимостей | **Беру** |
| Пакеты, которые не нужны | Npgsql, ClosedXML, OpenXml, ExcelDataReader, Markdig, AvaloniaEdit, ProtectedData; PDFsharp — позже, для инструментов | **Не беру** |
| Два таргета (`net10.0` и `net10.0-windows10.0.17763`) | Windows-таргет нужен только ради системных уведомлений Windows | **Беру** — по макету (уведомления в «Общем») |
| `Directory.Build.props` | весь вывод сборки в `artifacts/` | **Беру** |
| `nuget.config` | кеш пакетов внутри репозитория (`packages/`), только nuget.org | **Беру** |
| `.gitattributes`, `.gitignore` | LF для текстов и `.sh`, базы и кеши не в git | **Беру** |
| `dotnet-tools.json` | `dotnet-ef` для миграций | **Беру**, версию выровнять с EF Core |
| `global.json` | в SmartBase нет | **Добавлю** — закрепить SDK 10 |
| `app.manifest` | DPI PerMonitorV2; в SmartBase файл лежит, но к проекту не подключен | **Адаптирую** — подключу |
| `BannedSymbols.txt` | запрет сетевых API, нарушение — ошибка сборки | **Адаптирую** — запрет всей сети без исключений: программе сеть не нужна, сетевые папки — это файлы |

## 4. Запуск и оболочка программы

| Что | О чем | Решение |
|---|---|---|

| `App.axaml(.cs)` | заставка, подготовка в фоне, стили, корректное закрытие | **Адаптирую** — без мультибазы и расширений |
| Журнал `Logging/` | Serilog → `logs.db` на 30 дней, `crash.log`, медленные операции, детектор зависаний интерфейса, чтение журнала для экрана «Диагностика» | **Беру** — по макету |
| Настройки `AppSettings` | стандартные значения в коде, в базе — только отличия; при разработке данные в `.localdata/` | **Адаптирую** — новый небольшой класс |
| `Scaling`, `FontScale`, `WindowZoom` | масштаб интерфейса и размер шрифта | **Беру** — по макету («Оформление») |
| `SingleInstance`, `Sizes`, `Plural`, `TimeText`, `EtaEstimator`, `DbErrors` | один экземпляр, размеры, склонения, время, оценка «осталось около …», ошибки занятой базы | **Беру** |
| `Autostart` + фоновый режим со значком у часов | запуск при входе в систему, работа при закрытом окне | **Беру** — по макету |
| `Notifications/` | системные уведомления Windows, macOS, Linux | **Адаптирую** — по макету: только «новые документы» и «чтение закончено» |
| `Setup/` | тот же файл с именем `…-Setup` ставит программу без прав администратора, удаляет ее, обновляет из папки в сети | **Адаптирую** — по макету («О программе» → обновления) |
| `ListenerPermissions`, `SecretProtector`, `CurrentUser`, `Pg*` | приемник HTTP, секреты, пользователи, PostgreSQL | **Не беру** |

## 5. База и ядро библиотеки

| Что | О чем | Решение |
|---|---|---|
| `library.db` | новая база на EF Core с одной начальной миграцией: источники, группы, метки, документы, настройки | **Пишу заново** |
| `DocIndex/` | `docs_index.db` с FTS5 (`unicode61 remove_diacritics 2`), пересоздается при повреждении; фоновая очередь чтения с ходом и оценкой времени | **Беру** — ядро программы |
| `Core/Documents/` | `PdfGate` (все вызовы PDFium через одну очередь), миниатюры, страницы PDF и места слов, текст PDF, подсветка найденного, геометрия страницы | **Беру** — только PDF |
| `SqliteGate` | обход гонки пула Microsoft.Data.Sqlite | **Беру**, пока EF Core 9; уберу, если перейдем на версию с исправлением |
| `WalCheckpointer`, `SqliteMaintenance` | сжатие журнала WAL и разросшихся файлов | **Беру** |
| Наблюдение за папками | в SmartBase его нет | **Пишу заново** — `FileSystemWatcher` плюс периодическая сверка для сетевых папок, где события теряются |
| Мультибаза, PostgreSQL, `ChangePoller`, `NetworkPath`, резервное копирование | — | **Не беру** (резервное копирование убрано из макета) |

## Открытые вопросы

1. **Правила git как в SmartBase** — автор Roman Burov, сообщения по-русски `тип(область): суть`, без
   подписей ИИ, `main` только fast-forward.
2. **Worktree для нескольких чатов** на вашем компьютере — нужен ли этот процесс, или работаете в одном
   чате или в облаке.
3. **Встроенная инструкция пользователя** — добавить в настройки раздел «Инструкция», как в SmartBase,
   или не нужно.
4. **Иконка программы** — нужна своя.
5. **Техническое имя** — `PdfLibrary`: `PdfLibrary.exe`, `PdfLibrary-Setup.exe`, папка данных
   `PdfLibrary`, как в макете на экране «О программе».
6. **Тип документа** — определять автоматически по коду ЕСКД в имени файла («ВО» — чертеж общего вида,
   «РЭ» — руководство), остальные — по папке или без типа.

## Решения и как сделано (20.10.2026)

Ответы на открытые вопросы:

1. Правила git — как в SmartBase; основная ветка репозитория — `master`.
2. Процесс рабочих папок (worktree) — берется: `Scripts/worktree.sh`, AGENTS.md пункты 1–7.
3. Встроенной инструкции пользователя нет.
4. Иконка — временная, в стиле SmartBase (`Scripts/draw-icon.py`); своя — пункт ROADMAP.
5. Техническое имя — `PdfLibrary`.
6. Тип документа — по коду ЕСКД в имени файла, затем по словам в имени и в названии из свойств PDF,
   по папке; иначе без типа.

Отличия от плана:

- Стенд панели чтения (`Tests/DocReader`) заменен стендом всех экранов `Tests/Screens`: первый
  запуск, лента, поиск, панель чтения, настройки, темная тема.
- Кеш прочитанного называется `library-cache.db`, а не `docs_index.db`.
- Интеграционные тесты и стенд экранов гоняются и в проверке веток агентов (у программы нет
  PostgreSQL, наборы быстрые).
- Еще не перенесены `Tests/Benchmarks` и обслуживание SQLite (`WalCheckpointer`,
  `SqliteMaintenance`) — открытые пункты [ROADMAP](ROADMAP.md).
