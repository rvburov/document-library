# Tests/

Тесты и стенды «Библиотеки PDF». Перед коммитом — `./Tests/run-all.sh`: все три проекта подряд, с
остановкой на первом красном.

| Проект | Что это | Запуск |
|---|---|---|
| `Unit` | быстрый гейт без базы и файлов: тип документа, подсветка, геометрия страницы, порядок и фильтры ленты, установщик, автозапуск, склонения, размеры, правила проекта (нет сети, нет «е с точками», PDFium через `PdfGate`, SQLite через `SqliteGate`) | `dotnet test Tests/Unit` |
| `Integration` | настоящая SQLite и настоящие PDF: `library.db`, проверка папок и наблюдение, чтение текста и форматов, кеш и поиск FTS5, миниатюры с проверкой пикселей, страницы и места слов, журнал, связка уведомлений с D-Bus | `dotnet test Tests/Integration` |
| `Screens` | стенд экранов: настоящее главное окно без экрана (Avalonia.Headless со Skia) на подготовленной библиотеке; проверки и кадры PNG | `dotnet run --project Tests/Screens [-- папка-для-кадров]` |

## Unit

Своих зависимостей нет: ни базы, ни файлов, ни Avalonia. Тесты правил проекта читают исходники
(`RepoFiles`) и ломаются, если в код попал сетевой вызов, буква «е с точками», прямой вызов PDFium
или SQLite мимо ворот.

## Integration

PDF собираются в самих тестах: `HandPdf` пишет файл руками — листы любых размеров, повернутые,
обрезанные, текст наклонный и боком, название в свойствах (латиница или UTF-16), — а
`TempLibrary` дает временную папку данных с `library.db`. `LibraryServiceTests` гоняют библиотеку
целиком: папка → проверка → чтение в фоне → поиск по тексту и по названию, пропавший файл,
наблюдение за папкой, недоступная папка, уточнение типа по названию.

`LinuxNotificationsTests` — `[SkippableFact]`: без шины D-Bus он уходит в Skipped. По-настоящему он
выполняется под `dbus-run-session` — на Linux так и запускать:

```bash
dbus-run-session -- dotnet test Tests/Integration --filter 'FullyQualifiedName~LinuxNotificationsTests'
```

## Screens

Половина того, что ломается в интерфейсе, ломается не в числах: ресурс в разметке (иконка, кисть,
тема кнопки) разрешается при загрузке, и опечатка в ключе роняет экран в тот момент, когда человек
его открыл; привязка к несуществующему свойству молча показывает пустоту. Стенд открывает все
экраны и проверяет:

- первый запуск: пустая библиотека, три источника, чтение 8 документов и одного скана;
- ленту: 9 карточек, заголовок навбара, группа и узел «Метки» в боковой панели, панель разделов
  шириной 48, ручка ширины, поиск «насос центробежный», строки с подсветкой, строка состояния,
  выбор документов без нижней плашки действий, фильтры типа и метки;
- панель чтения: только страницы, без переключателя режимов, 8 страниц, счетчик, `F3` /
  `Shift+F3` клавишами в окно, строка про скан без текстового слоя, обе ручки ширины, форматы
  чертежа A1 + 2 × A3, закрытие кнопкой навбара;
- настройки: шесть разделов из боковой панели, диагностика читает журнал, открытие настроек не
  меняет масштаб и шрифт;
- темную тему.

Документы стенда — те же, что в согласованном макете (`SamplePdfs`): руководство, чертеж общего
вида, схема, спецификация, протокол, скан паспорта, ГОСТ, СП, договор. Русский текст пишется
вложенным шрифтом TrueType из системы; нет шрифта с кириллицей — латиницей.

Кадры (`01-welcome` … `17-feed-dark`) ложатся в `artifacts/screens` или в папку из аргумента; их
сверяют с макетом глазами. Расхождение в проверках — код возврата 1.

## Правила

- **Тесты гонять всегда**: по ходу работы — `dotnet test Tests/Unit`, перед коммитом —
  `./Tests/run-all.sh`. В отчете — числа прогона; упавшее или пропущенное не выдавать за прошедшее.
- **Новый тест проверять мутантом**: испортить код и убедиться, что тест падает.
- **Проверенное на стенде — не то же, что у пользователя**: настоящие файлы, сетевой диск и
  установка — по [чек-листу ручной проверки](../docs/developer/qa-checklists/manual-check.md).
- В облачной среде без русской культуры гонять с `LANG=ru_RU.UTF-8` (тестовые сборки и так ставят
  ru-RU сами, переменная — для `dotnet` и скриптов).
- Сборки и прогоны в одной рабочей копии — по одному: все проекты пишут в один
  `artifacts/bin/PdfLibrary`.
