# Библиотека PDF

Desktop-приложение для поиска и чтения PDF-документов: лента карточек с миниатюрами, поиск по тексту
внутри файлов с подсветкой, панель чтения и метки.

Это самостоятельная версия раздела «Библиотека документов» из
[SmartBase](https://github.com/rvburov/SmartBase), которая работает только с PDF. Технологии и принципы
те же: Avalonia UI 11.2 и .NET 10, EF Core 9 + SQLite с FTS5, PdfPig, Docnet.Core (PDFium).
Сервер и учетные записи не нужны, документы остаются файлами на своих местах.
