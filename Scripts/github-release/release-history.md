# История релизов

Что изменилось в каждой выпущенной версии. Отсюда `release-notes.sh` собирает тело релиза
на GitHub, поэтому файл лежит внутри модуля выпуска, а не в корне репозитория.

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
нумерация — [SemVer](https://semver.org/lang/ru/) в трактовке настольного приложения:

- **MAJOR** — несовместимая миграция базы или смена формата данных (откатиться назад нельзя);
- **MINOR** — новая заметная возможность: экран, раздел настроек, вид поиска;
- **PATCH** — исправления, производительность, рефакторинг.

Правки пишутся в секцию `## [Не выпущено]` по ходу работы. Перед выпуском секция переименовывается
в номер версии вручную, дату проставляет [release.sh](release.sh) — см.
[руководство по выпуску](../../docs/developer/guides/release.md).

Разделы внутри версии — только непустые: **Добавлено**, **Изменено**, **Исправлено**,
**Удалено**, **Безопасность**.

## [1.0.0] — 2026-10-21

### Добавлено
- Лента PDF-документов из подключенных папок — локальных и сетевых: карточки с миниатюрой первой
  страницы, где лежит файл, тип документа, метки, размер, число страниц и форматы листов.
- Поиск внутри документов: по тексту PDF и по названию с именем файла сразу, найденное
  подсвечено в карточке строками из текста. Сортировка по релевантности, названию, дате и размеру.
- Тип документа определяется сам: по коду ЕСКД в имени файла («ВО», «РЭ», «Г3»), по словам в имени
  и в названии из свойств PDF, по папке. Фильтр «Тип документа».
- Панель чтения справа от ленты: страницы документа друг под другом, найденное подсвечено на
  листах, переходы по совпадениям, ширина панели — ручкой, документ разворачивается на всю
  ширину, форматы листов чертежей.
- Источники и группы источников в боковой панели, метки документов с цветом, действия с выбранными:
  метка, копирование в папку.
- Наблюдение за папками: новые и измененные PDF появляются сами, удаленные помечаются «файл не
  найден»; пропавшая сетевая папка помечается недоступной без потери документов.
- Текст читается в фоне с ходом и оценкой оставшегося времени; сканы без текстового слоя ищутся по
  названию.
- Настройки разделами в боковой панели: общее (автозапуск, работа в фоне со значком у часов,
  уведомления), источники и чтение, лента и карточки с живым примером, оформление (светлая и темная
  темы, масштаб, размер шрифта), диагностика с журналом и выгрузкой в CSV, о программе с папкой
  обновлений.
- Окно из панели разделов, боковой панели, ленты и панели чтения; ширина боковой панели и панели
  чтения меняется ручками и запоминается.
- Установка без прав администратора тем же файлом с окончанием имени `-Setup`, удаление ключом
  `--uninstall`, обновление из папки обновлений.

## [0.1.0] — 2026-10-20

### Добавлено
- Номер версии в коде до первого выпуска; релиза на GitHub с этим номером нет. Возможности первой
  версии описаны в секции «Не выпущено» — при выпуске она получит номер следующей версии.
